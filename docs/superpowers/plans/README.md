## 使用方式

1. 从 001 开始，按序号顺序执行
2. 每个 Plan 完成后**立即验证**其验收标准 → 通过再进入下一个
3. Plan 共用一个 `app.py`，后续 Plan 在已有代码上**追加**（不要覆盖）
4. 全部 12 个 Plan 完成后，对照 Spec 第八节验收标准做端到端测试
